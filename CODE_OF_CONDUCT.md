# AI Keeper Code of Conduct

## Our pledge

We want AI Keeper to be a project where anyone can report a bug, ask a question or send a change without it being unpleasant.
We pledge to keep the community focused on the project and the code around it, and to be welcoming whatever your experience, background or tools.

## Community standards

- Keep interactions respectful and focused on the project. Critique the code or the idea, never the person.
- Assume good intent, and ask when something is unclear before assuming the worst.
- Use English for issues, pull requests, code comments and names, so that everyone can follow along.
- Contributors are expected to follow the [contributing guide](CONTRIBUTING.md).
- Do not publish other people's private information, and do not paste credentials or tokens into issues. Redact paths and project names if they are sensitive.

## Using AI tools

Most of the work this project does is about AI coding agents, and using them to build it is fine. The rules are about responsibility:

- You are expected to understand any change you propose, and to be able to explain it.
- Say so in the pull request if an AI tool wrote or substantially shaped the change (the template asks for the tool and what it was used for).
- Write issues and discussion in your own words. A translation tool is welcome if English is not your first language.
- Generated, unreviewed changes will be closed. Maintainers' time is the scarce resource here.

## Scope

This code of conduct applies in the repository (issues, pull requests, discussions, reviews), and wherever someone represents the project in public.

## Enforcement

Maintainers may edit or remove comments, close or lock threads, and decline contributions that do not follow this code of conduct.
Repeated or serious problems are handled in steps:

1. A warning.
2. A temporary ban.
3. A permanent ban.

## Reporting

If someone is not following this code of conduct, report it to the maintainer, [@chungquantin](https://github.com/chungquantin), through GitHub:
use "Report content" on the comment, or open a private security advisory titled "Conduct report" in this repository's Security tab.
Reports are kept confidential, and you will hear back.
