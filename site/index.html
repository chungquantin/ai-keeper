Where the space went

See exactly what is taking your disk.

One bar shows your whole disk by category, then the biggest folders with a plain explanation of each. Build output and caches are marked safe because the next build recreates them.

  • Developer, Library, tool folders and apps at a glance
  • Explore any folder, or clean it in one click
  • Rescan on demand; results stay cached until you ask
Workspaces

Know which worktrees are still needed.

Every workspace shows its Git state and pull request. Merged or closed PRs with a clean tree are marked safe to remove; anything with unpushed work is flagged, with the reason spelled out.

  • PR open, merged or closed, and CI status
  • Uncommitted files and unpushed commits
  • Size of build folders per workspace
Agents

Watch what is running right now.

See every running agent across tools, what it is working on, its CPU and the cost of the session.

  • Live CPU, memory and spend per agent
  • MCP servers and the processes they start
  • Workspaces with a running agent are left alone
AI usage

Track spend across every tool.

Daily and weekly cost by model, read from the logs on your machine. Set a budget and get warned before you pass it.

  • Claude, Codex and Pi in one chart
  • Codex rate limits at a glance
  • Nothing leaves your Mac
System

A health check that fits in the sidebar.

CPU, memory, disk and network in one live view, with the processes that matter to developers grouped together so a runaway build is obvious.

And the rest

Orphaned folders from tools you removed, found and sized.

Duplicates

Containers

Docker and OrbStack images, volumes and build cache with a safe prune.

Recently removed

Unsaved work is snapshotted before a workspace goes, so it can be restored.

Background cleanup

Cleanups run in the sidebar with progress while you keep working.

CLI and MCP

Scan from the terminal, or let your agent ask what is safe to clean.

Safety first

Nothing is deleted without you seeing it.

Every cleanup starts with a confirmation that lists exactly what goes and how much it frees. Workspaces with unsaved work are saved first, and anything with a running agent is left alone.

  • Preview before delete, every time
  • Snapshot of unpushed and uncommitted work
  • Runs on your Mac, no account and no telemetry
