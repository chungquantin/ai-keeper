Your coding agents leave gigabytes behind.

AI Keeper finds the worktrees, build folders and caches that Claude Code, Codex, Conductor and other agents leave on your Mac. It tells you which are safe to delete, then cleans them up in the background.

brew tap chungquantin/ai-keeper https://github.com/chungquantin/ai-keeper
brew install --cask ai-keeper

    Know what is safe to delete.

    Every worktree gets a plain answer: still needed, or done. AI Keeper reads the git state and the pull request, so a merged branch with nothing unsaved is marked as safe, and a folder with uncommitted work is never.

    It looks in the places each tool keeps its worktrees: Claude Code, Conductor, Codex, Superset, and plain git.

    Cleaning runs in the background.

    Deleting a 500 GB build folder takes minutes. AI Keeper does it in parallel, shows real progress with a time estimate, and keeps going when you close the window or switch apps.

    Queue more cleanups behind it, stop one at any time, and get a notification when it finishes. Before a workspace is removed, its unpushed commits and uncommitted changes are saved so you can restore them.

    Your agents can use it too.

    A command-line tool and an MCP server let an agent check free disk space before a big build, or clean up the build folders in its own worktree when it finishes.

    Every action is a dry run unless the agent confirms it, and it can only touch build folders that AI Keeper has already attributed to that workspace.

    $ aikeeper status
Disk         661 GB free of 994 GB
Agents       8 running, 1 needs you
Rebuildable  45 GB in build folders

$ aikeeper clean-artifacts ~/code/my-service
{ "dry_run": true, "would_free_gb": 9.9, … }

$ claude mcp add aikeeper -- aikeeper mcp

    Careful by default.

    Cleanup tools earn trust by what they refuse to do.

    • Unsaved work is never marked safe.A worktree with uncommitted changes needs your explicit say-so, and shows in red.
    • A snapshot comes first.Unpushed commits, the uncommitted diff and untracked files are kept for 30 days, with a one-click restore.
    • Running agents are left alone.A folder an agent is working in is skipped, so a build never disappears under it.
    • Main checkouts stay.Only their build folders are cleaned, never the repository itself.
    • The Trash comes first.Workspaces go to the Trash unless you choose to delete them. Build folders are deleted directly, because your next build recreates them.

    Install

    AI Keeper runs on macOS 14 Sonoma or later, on Apple silicon and Intel.

    Homebrew

    Also puts the aikeeper command on your PATH. Needs Homebrew 7 or later.

    brew tap chungquantin/ai-keeper https://github.com/chungquantin/ai-keeper
brew install --cask ai-keeper

    Download

    Get the zip from the latest release and drag AI Keeper to Applications. The app is not notarized yet, so the first time you open it, right-click it and choose Open.

    Build from source

    Needs the Swift toolchain that ships with Xcode or the Command Line Tools.

    git clone https://github.com/chungquantin/ai-keeper
cd ai-keeper && ./scripts/install.sh
