Your coding agents leave gigabytes behind.

AI Keeper finds the worktrees, build folders and caches that Claude, Codex, Conductor and other agents leave on your Mac, shows which are safe to delete, and clears them in the background. Use the Mac app, or the keeper command.

Free. Needs macOS 14 or later. Apple Silicon and Intel. Nothing leaves your Mac.

Works with the agents you already use.

AI Keeper looks in each tool’s own folders, so there is nothing to connect or sign in to. Switch any of them off in Settings.

Names and logos belong to their owners and are used only to identify the tools.

Pick what goes. The reason sits beside each one.

Every workspace shows its Git state and pull request. A merged PR with a clean tree is safe to remove. Work you have not pushed is flagged, saved first, and never selected for you.

Workspaces with a running agent are skipped.

Files go to the Trash, or to a vault you can restore from.

Everything the app does, from your terminal.

Run keeper for a full-screen dashboard, or call any command from a script. Anything that deletes is a preview until you add --yes.

keeper

    

    

      
keeper workspaces --deprecated
What is no longer needed, biggest first.

      
keeper skills remove --risk danger
Quarantine the risky ones. Restore any of them later.

      
keeper agents
What is running, what it costs, and stop one.

      
keeper usage --by model
Spend by model, tool, day or project.

      
keeper disk explore ~/Library
See what is inside any folder, biggest first.

      
keeper ui
The full-screen dashboard. Same as typing keeper.

    

    
For scripts and agents, add --json to any command. To let Claude Code run it: claude mcp add keeper -- keeper mcp

Check every skill your agents can load.

      
Skills run with your permissions, so a bad one is a risk. AI Keeper lists every installed skill and scans them with NVIDIA SkillSpector, locally and without an AI model.

Nothing is deleted before you see it.

    

      
You see the list first
Each cleanup opens a list of exactly what will go and how much space it frees. Commands are a dry run until you add --yes.

      
Unsaved work is saved first
Uncommitted files and unpushed commits are saved to a vault before anything is removed, so you can bring a workspace back.

      
It stays on your Mac
No account, no upload. Scanning skills looks up known vulnerabilities by package name, and nothing else leaves the machine.
