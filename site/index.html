Your coding agents leave gigabytes behind.

AI Keeper shows which worktrees, build folders and caches Claude, Codex, Conductor and other agents left on your Mac, which are safe to delete, and clears them in the background. Use the Mac app, or the keeper command in your terminal.

See it in action.

A 45-second walkthrough: where the disk went, which worktrees can go, and a cleanup running in the background.

See where the disk went.

One bar splits your disk into developer files, library, tool folders and apps. Below it, the biggest folders each get a plain explanation, and a Clean button when the contents can be rebuilt.

Know which worktrees are still needed.

Each workspace shows its Git state and pull request. A merged PR with a clean tree is safe to remove. Unpushed commits and uncommitted files are flagged, with the reason beside them.

Watch what is running, and what it costs.

Agents lists every running Claude, Codex and other agent with its CPU, memory and session cost. Usage charts daily spend by model from logs on your Mac, and warns you at the budget you set.

A health check in the sidebar.

CPU, memory, disk and network in one live view. Developer processes are grouped, so a runaway build stands out.

Also in the app

Leftovers

Folders from tools you removed, found and sized.

Duplicates

Identical large files, checked by content before anything is offered.

Containers

Docker and OrbStack images, volumes and build cache, with a safe prune.

Recently removed

Unsaved work is saved before a workspace is deleted, so you can restore it.

Skills

Every skill your agents can load, scanned with NVIDIA SkillSpector for prompt injection, data exfiltration and risky scripts. Each finding shows the code it points at.

Background cleanup

Cleanups run in the sidebar with progress while you keep working.

The keeper command, and MCP

Every feature is a keeper command, with JSON output. Or let your agent ask what is safe to clean.

Everything the app does, from your terminal.

Run keeper for the dashboard, or use any command in a script. Anything that deletes is a preview until you add --yes, and files go to the Trash. Homebrew installs it with the app.

keeper status
Disk, what you can reclaim, running agents, spend.
keeper workspaces --deprecated
What is no longer needed, biggest first.
keeper remove --all-safe
Preview, then add --yes. Unsaved work is saved first.
keeper skills scan --all
Check every skill your agents can load, with NVIDIA SkillSpector.
keeper skills remove --risk danger
Quarantine the risky ones. Restore any of them later.
keeper agents
What is running, what it costs, and stop one.
keeper usage --by model
Spend by model, tool, day or project.
keeper disk explore ~/Library
See what is inside any folder, biggest first.

For scripts and agents

Every command takes --json. Exit codes mean something: 0 done, 1 failed or everything you named was skipped, 2 wrong usage. keeper skills scan exits 1 when a skill is rated do-not-install, so it can gate an install.

An MCP server lets an agent check free space and clean its own build folders.

$ keeper status --json { "disk": { "free_bytes": 612400000000, "low": false }, "reclaimable": { "total_bytes": 107900000000 }, "agents": { "running": 5, "need_you": 1 } } $ claude mcp add keeper -- keeper mcp

Nothing is deleted before you see it.

Each cleanup opens a list of exactly what will be removed and how much space it frees. Unpushed and uncommitted work is saved first, and workspaces with a running agent are skipped.

Everything runs on your Mac. No account needed.

Get your disk back.

Download the app, or install it with Homebrew. Homebrew asks you to trust the tap once, because it is not an official one.

Download for macOS View source
$ brew tap chungquantin/ai-keeper https://github.com/chungquantin/ai-keeper $ brew trust --tap chungquantin/ai-keeper $ brew install --cask ai-keeper

Or install from Terminal, which also skips the macOS warning below:

$ curl -fsSL https://chungquantin.github.io/ai-keeper/install.sh | bash

The app is not notarized yet, so macOS warns when you open a zip downloaded in a browser. To open it anyway, go to System Settings, Privacy & Security, scroll down and click Open Anyway. Homebrew and the Terminal command don't trigger the warning.
